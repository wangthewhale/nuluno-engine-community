# S01: verify an existing product and offer

The free starter contains the original full nine-step S01 contract/procedure and executable result checks. Stable step IDs are shared with the optional commercial library so an upgrade cannot silently rewrite queued S01 work. The preserved legacy contract text is in Traditional Chinese; this guide explains the same steps in English.

1. Inventory public product, pricing, delivery and demo sources; save each URL and observation time.
2. Verify what the existing product actually does. Preserve contradictions instead of combining unsupported claims.
3. Distinguish native software, human services and items not yet delivered.
4. Verify currency, billing period, offer and expiry. Unknown prices remain unknown.
5. Read the existing signup/purchase entry; record reachability without creating accounts or purchasing.
6. List evidence that can be cited and its allowed use. A publisher claim is not independent efficacy proof.
7. Record unavailable features and commercial promises the agent cannot make.
8. Deliver source-bound facts, the existing offer URL, limitations and unknowns; preserve the version used by later work.
9. Record when or on which change to verify sources again. Preserve earlier receipts/history.

An MCP agent uses run_create, acquire/heartbeat, exact read_public_source and complete with the original lease/digest and per-step evidence. The tiny public demo verifies the source/recovery/authentication path; it deliberately does not pretend that these nine research judgments or a sales goal are complete. The catalog API supports kind=skill, skill_id=S01 with at most two steps per response, so the complete procedure can be read without injecting a full methods library.
