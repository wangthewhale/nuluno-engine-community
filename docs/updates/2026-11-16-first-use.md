# A sales task should survive the next agent run

## English feature post

I built Nuluno Engine because asking an agent to help sell a product should not mean explaining the job again every session.

The new public trial runs with one command. It reads a real page, starts a new process with the **same task and receipt**, then revokes the key and proves a fresh process cannot keep using it. You get a saved research brief and a machine-readable record, not a fabricated sale.

```sh
node scripts/try-first-use.mjs
```

This is a current-source addon. The trial used unchanged Engine 0.13.0a2 core and helper on macOS/arm64, with real public reads and expected exits `[0, 0, 0, 3]`. Repeating the driver displays the original result without another provider action.

[Try the free core](https://github.com/wangthewhale/nuluno-engine-community/blob/main/docs/one-command-trial.md) · [Read the actual receipt](https://github.com/wangthewhale/nuluno-engine-community/blob/main/docs/evidence/one-command-first-use-20261116.json)

Tell your agent:

> Read https://raw.githubusercontent.com/wangthewhale/nuluno-engine-community/main/docs/one-command-trial.md . Explain the local installation and public-read scope. With my setup authorization, use a reviewed checkout and run the trial. Preserve any existing workspace/state. Show the original receipt and any real failure; do not create replacement tasks to claim success.

The Apache-2.0 community core includes the S01 starter. The separate commercial library contains 99 goal loops, 134 graphs and 188 install folders. Those are shipped library counts; they are not 99 verified sales outcomes. [Compare the product](https://engine.nuluno.com/?lang=en).

我做 Nuluno Engine，是因為請 AI 幫忙賣產品，不應該每換一次對話，就要重新交代整個工作。

這次以未修改的 0.13.0a2 核心與原 helper，在 macOS/arm64 跑通 `[0, 0, 0, 3]`；最後的 3 是預期的「撤銷後被拒絕」。再跑一次會讀回既有記錄，不會重做同一個 provider 動作。

## Separate learning update: reject an incomplete improvement

Three AI-written method revisions were frozen before testing three new source cases each. All three were rejected. In the last revision, the candidate recovered 7 of 9 required facts versus the baseline's 2 of 9, but incomplete coverage still prevented adoption. The demonstration preserves those failures rather than labelling every new method an improvement.

[Inspect the executable method-learning demonstration](https://github.com/wangthewhale/nuluno-engine-community/tree/main/examples/method-learning). This was initialized by a coding agent; it does not establish unattended invention, model-weight training or improved sales.

繁中：新的方法找到更多資料，也不等於可以採用。最後一版從原本的 2／9 提高到 7／9，仍未達預先設定的完整度，所以沒有取代原方法；三版被拒絕的記錄都保留在公開示範中。
