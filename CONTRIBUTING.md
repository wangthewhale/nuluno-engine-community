# Contributing to Nuluno Engine Community

The community runtime and S01 starter are Apache-2.0; see LICENSE and NOTICE. Separately licensed commercial methods are not part of this repository. Do not commit commercial pack contents, credentials or customer data.

Run `.venv/bin/python -m unittest tests.test_artifact_evolution tests.test_method_packs -v` and the gateway compatibility checks. Positive commercial-library tests require a separately obtained licensed ZIP through `NULUNO_TEST_COMMERCIAL_PACK`; without it they are explicitly skipped, never presented as verified. Controlled fixtures are not sales evidence.

Preserve original run/task/lease identities, account authority and budgets. Keep source receipts immutable and missing costs unknown. Proposals cannot self-approve validation or promotion. Changes to security boundaries need meaningful regressions. Report security issues privately as described in SECURITY.md.

## Portable method proposals

Run `python3 community/method_pack.py community/examples/normalize-query --with-engine-kernel` in a community installation. See [the contribution format](community/README.md). Valid proposals remain unadopted and carry no account authority.
